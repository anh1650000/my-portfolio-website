# Phạm Duy Anh — Portfolio

A responsive, bilingual portfolio for **Phạm Duy Anh**, inspired by the editorial/technical rhythm of the supplied reference while using original layout details, copy and visual assets.

## Preview locally

No build step or dependencies are required.

```powershell
python -m http.server 4173
```

Then open `http://localhost:4173`.

## Files

- `index.html` — semantic page content, SEO metadata and structured data
- `styles.css` — responsive visual system, animation and layout
- `script.js` — EN/VI switcher, navigation, scroll state, reveal effects and email copy action

## Deploy

Upload the three site files to any static host (Cloudflare Pages, GitHub Pages, Netlify, Vercel or a conventional web server). Set `index.html` as the entry document.
